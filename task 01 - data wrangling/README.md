# 📊 Task 01 – Data Wrangling

## ApexPlanet Software Pvt. Ltd. – Data Analytics Internship

---

# 📌 Project Overview

This project is the first task of the ApexPlanet Data Analytics Internship. The primary objective is to clean and prepare the raw e-commerce dataset for further analysis by handling missing values, validating data quality, and performing necessary preprocessing steps.

A clean and reliable dataset serves as the foundation for all subsequent analytics and visualization tasks.

---

# 🎯 Objective

* Load the raw dataset.
* Inspect data quality.
* Handle missing values.
* Remove duplicates.
* Correct data types.
* Perform feature engineering.
* Prepare an analysis-ready dataset.

---

# 📂 Dataset

**Dataset:** E-commerce Customer Dataset

The dataset contains customer transaction records including:

* Order Details
* Customer Information
* Product Information
* Sales Data
* Demographic Information

---

# 📈 Workflow

1. Import required libraries.
2. Load the dataset.

5. Remove duplicate records.

7. Create derived features.
8. Save the cleaned dataset.
