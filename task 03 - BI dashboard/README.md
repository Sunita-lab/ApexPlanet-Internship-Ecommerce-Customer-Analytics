# 📊 Task 03 – Interactive Dashboard

## ApexPlanet Software Pvt. Ltd. – Data Analytics Internship

---

# 📌 Project Overview

This project is the third task of the ApexPlanet Data Analytics Internship. The objective is to design an interactive Power BI dashboard that enables business users to monitor key performance indicators (KPIs), explore customer behaviour, and support data-driven decision-making.

The dashboard transforms analytical findings into an intuitive visual reporting system.

---

# 🎯 Objective

* Design an interactive dashboard.
* Present business KPIs.
* Enable interactive filtering.
* Visualize customer and product performance.
* Support executive decision-making.

---

# 📂 Dataset

**Dataset:** Cleaned E-commerce Customer Dataset

The dashboard is built using the cleaned dataset generated in Task 01 and the analytical insights developed during Task 02.

---

# 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Python (Data Preparation)

---

# 📈 Dashboard Features

### Executive Overview

* Total Sales
* Total Orders
* Average Order Value
* Average Sales per Customer
* Repeat Purchase Rate

### Customer Analysis

* Customer Segmentation
* Gender Distribution
* Age Group Analysis

### Product Analysis

* Category-wise Revenue
* Product Performance
* Quantity Analysis

### Geographic Analysis

* City-wise Sales
* Regional Performance

### Interactive Features

* Month Slicer
* Cross-filtering
* KPI Cards
* Interactive Charts
